# income-dashboard (front-end)

個人の収入ダッシュボードの画面だけを置いたリポジトリ。GitHub Pages で配信する。

- **データはこのリポジトリに一切入っていない。** 表示するたびに Google Apps Script の JSON API から取得する
- API は合言葉（パスフレーズ）認証。合言葉はこのリポジトリにも含まれず、ブラウザで SHA-256 にしてから送られる
- 外部CDN・外部フォント・外部画像は使わない（単体で完結）
- 金額はこのリポジトリに1つも書かない。画面に出る数字はすべて API 応答から導出する

```
index.html      画面の骨格（DASH / 委託 / 毎月 / 経費 ＋ 追加シート）
css/skin.css    「地」の層：紙・テクスチャ・テープ・ステッカー・プレート・数字まわり
css/ui.css      触る部品：フォーム・ボタン・ナビ・ボトムシート・トースト・合言葉ゲート
img/*.webp      装飾ステッカー（実物のデザイン。透過WebP・合計32KB）
js/config.js    APIのURL・画面一覧・PALETTE（色の唯一の出所）
js/theme.js     PALETTE の流し込み（テーマは夜1本。切替は廃止）
js/api.js       通信と認証（DOMを触らない）
js/forms.js     入力フォームの定義・組み立て・値の取り出し・リセット
js/views.js     描画（データ → DOM）
js/sheet.js     ボトムシートの開け閉め（中身は知らない）
js/app.js       配線
```

## デザインの掟

`design/20260801_収入ダッシュボード_UIモック.html` から移植したもの。崩すと意味が変わる。

- がちゃつき（紙・テープ・ステッカー・ハーフトーン）は**地の層**に閉じ込める。
  数字は必ず**不透明な紙プレートの上**に、インキ黒で置く。数字の裏に半透明を敷かない
- 傾けるのは**ラベル・テープ・ステッカー・プレートの下敷き**だけ。数字カード自体は水平
- `position:fixed` を使ってよいのは、**操作の層は** `.nav` / `.sheet` / `.sheetbg` / `.toast` / `.gate`、
  **地の層は** `body::before` / `.grain`（どちらも全面・`pointer-events:none`）**の7つだけ**。
  本文に重なる fixed を増やさない（金額を覆う事故を構造的に断つため）。
  `css/ui.css` の冒頭にも同じ一覧がある。**「ここに書いてあるのが全部」と信じられる文書**なので、
  fixed を足す・消すときは必ず両方を直す（片方だけだと、次に触る人のガードが静かに緩む）
- 本文の最小コントラストは AA(4.5:1)。`.ghost` と `.hero-deco .word` だけは
  意図的な透かし（`aria-hidden`）なので対象外
- **テーマは夜（オフブラックの地）1本**（2026-08-03 オーナー指示で昼夜の切替を廃止）。
  地の色は `css/skin.css` の `:root` が持つ。`js/theme.js` は起動時に
  旧選択（`localStorage.inc_theme`）を消すので、以前「紙」を選んだ端末も夜で開く

## ステッカー（`img/*.webp`）

`.stick` は**オーナーが実際に販売しているステッカーのデザイン**（Square カタログの商品画像から
ダイカット部分を切り抜いた透過WebP）。ネットの拾い物は使わない（このリポジトリは public）。

縦位置が**プレートの上辺**に限られるのは、そこだけがどのプレートでも確実に空いているため
（下端は合計金額と操作ボタン。中身は全部が全幅ブロックなので左右の余白 16px にも逃がせない）。
**ただし横位置・大きさ・傾き・はみ出し量は必ずばらす。** 5枚を同じ角・同じ寸法・同じ角度で貼ると
「コラージュ」ではなく「ルール」に見え、飾りとして機能しない（2026-08-03 差し戻し）。

| 貼り先 | 絵柄 | 高さ | 傾き | プレート上辺からのはみ出し | 横 |
|---|---|---|---|---|---|
| DASH hero | apple-girl | 78px | +6° | 27% | 右へ 8px |
| DASH 内訳 | dino-boy | 50px | −21° | 14% | 18px 内側 |
| 委託 あずけ先 | cone-boy | 44px | +14° | 40% | 右へ 9px |
| 固定費 一覧 | bag-boy | 72px | −9° | 25% | 23px 内側 |
| 経費 一覧 | balloon-girl | 62px | +22° | 15% | 2px 内側 |

- 枚数は **DASH 2 / 委託 1 / 固定費 1 / 経費 1**。DASH に3枚あると1スクロールで同じ貼り方を3回見る
- **数字・本文の矩形に1pxも重ねない**。目視ではなく総当たりで確かめる。
  相手は要素の矩形ではなく**テキストノードの `Range.getClientRects()`**（実際のグリフ）＋押せる要素の矩形。
  要素の矩形だけを見ると `#heroNum` のように子を持つ箱を素通りする。
  飾り側は `img.stick` と `.tape`（上に乗る層）だけ。`.hero-deco` / `.ghost` / `.grain` は
  下に敷く透かしで、数字は不透明なプレートの上に乗るので対象外
- **右へのはみ出しは 11px まで**（`main` の左右余白が 13px）。回転で膨らむぶんを含めて内側に収める
  （`body` が `overflow-x:hidden` なので、切れていても横スクロールでは気付けない）
- **上へのはみ出しも 25px まで。** 各タブの先頭プレートは、それを超えるとトップバーの年・月セレクタに被る
  （飾りが操作を覆う＝いちばんやってはいけない事故）
- **暗い絵柄ほど地に沈む。** 不透明画素（alpha>128）の平均色と暗い地(`#17151A`)のコントラスト比は
  dino 9.75 / cone 9.54 / bag 8.83 / apple 7.86 に対し **balloon だけ 3.97**（他の半分以下）。
  同じだけ地に出すと経費タブの上半分が沈むので、balloon は上へのはみ出しを 15% に抑えてある。
  絵柄を差し替えるときは同じ測り方をやり直すこと（`img/*.webp` を RGBA で読み、
  alpha>128 の画素の平均色 → 地とのコントラスト比）
- `.hero-cap` は右 40px をステッカーの席として空けてある。空けないと、月を先に送って
  但し書きが伸びたとき（`2026.12・確定分だけ`）だけキャプションがステッカーの下に潜る
- 1枚あたり表示サイズの3倍・6KB前後。読めなかった `img.stick` は `app.js` が黙って外す
  （装飾なので無くても画面は成立する）。**`error` のリスナを付けるだけでは足りない**。
  `<img>` は body 上部、配線はファイル末尾なので、リスナが付く前に `error` が飛び終わっていることがある。
  付け終わったあとに `complete && !naturalWidth` で「もう落ちていた分」を拾い直す

## 入力の入口（案E）

下ナビは **DASH / 委託 / ＋ / 毎月 / 経費**。「毎月」は報酬（フリーランス収入）と固定費の2枚組。
ラベルが2文字なのは、320px で5等分した枠（64px）に「固定費・報酬」が収まらないため。
`data-go` は `fixed` のままにしてある（`?tab=fixed` の古いリンクを殺さないため）。
中央の「＋」は画面ではなく**追加シート**を開く。
シートで イラスト案件 / Epochstory販売 を選ぶ。委託・固定費・経費のフォームは各タブに置いたまま。

旧レイアウトの `?tab=input` は DASH を出したうえで追加シートを開く（リンクを殺さない）。

## 月の切替（トップバーの「◯月」）

年セレクタの隣に月セレクタを置いてある。**通信はしない**（bootstrap が12ヶ月ぶんの配列を返すので
画面だけ描き直す）。連動するのは **hero（その月の手残りと内訳チップ）/ 内訳リスト / 月次推移の選択枠**の3つだけ。

**年の数字（今年の総収入・今年の手残り・年末までの着地）は月に連動させない。**
連動させると過去月を選ぶたびに「今年の」が減って意味が壊れる。年の数字が見るのは常に `S.thisMonth`
（当年なら今月、過去年なら12月）。

- 年を変えたら、その年のいちばん新しい月に合わせ直す。同じ年の読み直し（保存のあと）では動かさない
- 先の月にも「フリーランス収入」の確定分だけは入っているので、**hero・月次推移・内訳の3つとも**
  但し書きを出す（`2026.12・確定分だけ` ／ `（9月〜は確定分）` ／ `12月の内訳・確定分だけ`）。
- **来年（年セレクタの一番上）はまるごと確定分。** サーバは当年以外に `thisMonth: 11` を返すので
  （`src/Api.gs`）、`thisMonth` 基準の分岐だけだと**過去年と未来年が同じ顔になり、
  確定分を「実績」と書いてしまう**。年をまたぐ判定は `isFutureYear()` に集約してあり、
  月次推移は `（ぜんぶ確定分）`、今年の総収入は `1〜12月の確定分`、
  年末までの着地は `12ヶ月ぶんの確定分（実績はまだ1ヶ月も無い）` になる。
  `thisMonth` 基準の分岐（`last > latest` / `remain > 0`）と混ぜないこと
  **内訳の前年同月比は、未来月では出さない**（`確定分だけなので前年比較はしない`）。
  「確定分だけの当年 ÷ 実績が揃った前年」は成長率として読めるのに意味を持たない
  （2026-08-03 に4桁の伸び率を出して差し戻された。月切替が新しく到達可能にした経路）
- **月セレクタは DASH 以外では `disabled`**。効かないのに押せる見た目のまま残すと、押した瞬間は
  何も起きないのに裏で DASH だけが書き換わり、「後で別の画面が変わっている」という一番読み違える形になる。
  年セレクタは全タブに効くのでそのまま
- **hero を左右スワイプしても前月／翌月に動く**（右上のセレクタは右手の親指から一番遠い角のため）。
  横の移動が 44px 以上、かつ縦の 1.5 倍を超えたときだけ効かせる（縦スクロールの途中で月が飛ばないように）。
  案内（`.swipe-hint`）は `@media (hover:none)` の環境にだけ出す
- URL は `?tab=dash&m=8`（月は1始まり）。範囲外・数字以外は黙って捨てて最新月で開く

## 通年見込（年末までの着地）

「ランレート」ではない。**実績（1〜今月）＋ 確定している残り月の収入**。
残り月の値はシートの「フリーランス収入」に入っている確定分だけで、物販とイラスト案件は
受注前なので 0 のまま入っている。画面側に月額の定数は持たない（契約が増減したらシートを直せば追随する）。

## 動作確認（2026-08-04 実測）

本番の数字は使わず、同じ形の架空データを差した控えで測ってある（金額を手元に落とさないため）。

- 合言葉なしでは画面に何も出ない（DOMにも数値が入らない）。間違えると「合言葉が違います。」
- 幅 320 / 375 / 414 / 768px の4つで、**4画面 × DASH は12ヶ月すべて**を回して
  横スクロール0 / 最下部までスクロールしてナビに隠れる金額0 / 飾りと文字（グリフ矩形）の重なり0
- 12月を選んだ月次推移の**ラベル最小間隔**：320px で 月 5.18px・値 5.18px（直す前は 1.3px / 2.5px）。
  375px は従来どおり 12px のままで 5.92px
- タップ領域は全要素 44px 以上（チェックボックスだけ的は 48px の `.chk` ラベル全体）
- コントラスト実測 最小値：本文 5.14 / 効かない月セレクタの**文字** 6.01
  （`opacity:.6`。`.45` だと 3.9 で AA を割る）。
  同じセレクタの **▼ は無効時だけ 1.89 まで落ちる**が、これは意図した消え方
  （ライムが「選択中」、▼ が「押せる」の合図なので、押せない状態では ▼ が引く）。
  無効な操作は WCAG 1.4.3 の対象外なので違反ではない。「最小値」に ▼ は数えていない
- ステッカーの画像を全部 404 にしても、5枚とも DOM から消えて画面は成立する
- 固定費：追加 → 編集 → 保存 → 続けて新規追加 で、編集した行が壊れず新しい行が末尾に入る
- 報酬：編集 → **トップバーで年を切り替える** → フォームが新規に戻っている
  （掴んだ行を持ったまま年を移ると、保存でその行の発生月が別の年に書き換わる）
  （`type="hidden"` の value は `form.reset()` で戻らないので `IncForms.reset()` が明示的に空にする）
- API の疎通を `curl` で確かめるときは **`-X POST` を付けない**。付けると302の後もPOSTのまま飛んで
  405になり、APIが死んでいるように見える（ブラウザの `fetch` では起きない）
