# income-dashboard (front-end)

個人の収入ダッシュボードの画面だけを置いたリポジトリ。GitHub Pages で配信する。

- **データはこのリポジトリに一切入っていない。** 表示するたびに Google Apps Script の JSON API から取得する
- API は合言葉（パスフレーズ）認証。合言葉はこのリポジトリにも含まれず、ブラウザで SHA-256 にしてから送られる
- 外部CDN・外部フォント・外部画像は使わない（単体で完結）
- 金額はこのリポジトリに1つも書かない。画面に出る数字はすべて API 応答から導出する

```
index.html      画面の骨格（DASH / 委託 / 固定費 / 経費 ＋ 追加シート）
css/skin.css    「地」の層：紙・テクスチャ・テープ・ステッカー・プレート・数字まわり
css/ui.css      触る部品：フォーム・ボタン・ナビ・ボトムシート・トースト・合言葉ゲート
js/config.js    APIのURL・画面一覧・PALETTE（色の唯一の出所）
js/theme.js     PALETTE の流し込みとテーマ切替（夜＝既定 / 紙）
js/api.js       通信と認証（DOMを触らない）
js/forms.js     入力フォームの定義・組み立て・値の取り出し・リセット
js/views.js     描画（データ → DOM）
js/sheet.js     ボトムシートの開け閉め（中身は知らない）
js/app.js       配線
```

## デザインの掟

`design/20260801_収入ダッシュボード_UIモック.html` から移植したもの。崩すと意味が変わる。

- がちゃつき（紙・テープ・ステッカー・ハーフトーン）は**地の層**に閉じ込める。
  数字は必ず**不透明な紙プレートの上**に、インキ黒で置く。数字の裏に半透明を敷かない
- 傾けるのは**ラベル・テープ・ステッカー・プレートの下敷き**だけ。数字カード自体は水平
- `position:fixed` を使ってよいのは `.nav` / `.sheet` / `.sheetbg` / `.toast` / `.gate` だけ。
  本文に重なる fixed を増やさない（金額を覆う事故を構造的に断つため）
- 本文の最小コントラストは AA(4.5:1)。`.ghost` と `.hero-deco .word` だけは
  意図的な透かし（`aria-hidden`）なので対象外

## 入力の入口（案E）

下ナビは **DASH / 委託 / ＋ / 固定費 / 経費**。中央の「＋」は画面ではなく**追加シート**を開く。
シートで イラスト案件 / Epochstory販売 を選ぶ。委託・固定費・経費のフォームは各タブに置いたまま。

旧レイアウトの `?tab=input` は DASH を出したうえで追加シートを開く（リンクを殺さない）。

## 通年見込（年末までの着地）

「ランレート」ではない。**実績（1〜今月）＋ 確定している残り月の収入**。
残り月の値はシートの「フリーランス収入」に入っている確定分だけで、物販とイラスト案件は
受注前なので 0 のまま入っている。画面側に月額の定数は持たない（契約が増減したらシートを直せば追随する）。

## 動作確認（2026-08-03 実測）

- 合言葉なしでは画面に何も出ない（DOMにも数値が入らない）。間違えると「合言葉が違います。」
- 幅375pxで4画面とも 横スクロール0 / 金額の折返し0 / 最下部までスクロールしてナビに隠れる金額0
- タップ領域は全要素 40px 以上
- コントラスト実測 最小値：夜 5.14 / 紙 5.37（本文）
- 固定費：追加 → 編集 → 保存 → 続けて新規追加 で、編集した行が壊れず新しい行が末尾に入る
  （`type="hidden"` の value は `form.reset()` で戻らないので `IncForms.reset()` が明示的に空にする）
- API の疎通を `curl` で確かめるときは **`-X POST` を付けない**。付けると302の後もPOSTのまま飛んで
  405になり、APIが死んでいるように見える（ブラウザの `fetch` では起きない）
